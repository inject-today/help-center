title: Downloading Potassium
description: Walks through obtaining the latest Potassium build via the official Discord bot.
category: getting-started
appliesTo: All versions
verifiedOn: 2026-11-19
---

- Join the official Potassium Discord server if you have not already.
**Verification:** You can see the server channels and the PSM bot is visible in the member list.
- Open a **direct message** with the **PSM bot**. You can click on the bot's profile in the server member list and select **Message**.
**Verification:** A DM conversation with the PSM bot is open.
- Send the following command: **/download**
- **Verification:** The bot responds with a download link or file attachment for the latest Potassium build.
- Download the provided `.zip` file and extract it to a folder on your PC (e.g., `C:\Potassium`). Do not place it inside `Program Files`, `OneDrive`, or any cloud-synced directory.
**Verification:** The extracted folder contains the Potassium executable and all supporting files.
- Before launching, add the entire Potassium folder to your Windows Defender exclusions. Open **Windows Security** → **Virus & threat protection** → **Manage settings** → **Exclusions** → **Add or remove exclusions** → **Add an exclusion** → **Folder** → select your Potassium directory.
**Verification:** The Potassium folder appears in your exclusions list and Defender will not quarantine its files.
- Open the extracted folder in File Explorer and double-click the Potassium executable **directly from the folder**. Do not use a shortcut.
**Verification:** Potassium launches and reaches the login/authentication screen.

## Still not working?

If the download doesn't work, try disabling Windows Defender.
