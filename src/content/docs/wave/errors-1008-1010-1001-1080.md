### Symptom
Wave displays one of the following error codes on launch or during injection: **1008**, **1010**, **1001**, or **1080**.

### Cause
The .NET 6.0 Desktop Runtime is missing or corrupted, or antivirus software is preventing Wave's components from loading.

### Fix
1. Download and install the [.NET 6.0 Desktop Runtime v6.0.33 (x64)](https://dotnet.microsoft.com/en-us/download/dotnet/6.0). Select the **Desktop Runtime** installer (not the standard runtime or SDK).  
   **Verification:** The installer completes successfully and reports that the .NET 6.0 Desktop Runtime is installed.
2. Restart your PC.  
   **Verification:** Your system reboots completely and you are back at the desktop.
3. Disable **Windows Defender Real-time protection** and any third-party antivirus software.  
   **Verification:** All active antivirus protections are temporarily disabled.
4. Right-click `Wave.exe` and select **Run as administrator**. If the error persists, right-click the Wave **installer** instead and run it as administrator, then reinstall.  
   **Verification:** Wave launches without displaying any of the 1008/1010/1001/1080 errors.

### Still not working?
Ensure all other dependencies (.NET 8.0 and Visual C++ redistributables) are installed. Missing runtime libraries can trigger cascading error codes.
